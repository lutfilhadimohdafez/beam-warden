## Corrected measurement path and real normal control (23:27)

New mt76 captures use the explicit `interval-v2` schema. They select the configured
station, preserve the true raw failed-transmission counter, elapsed sampling time
and activity count, and compute interval failure fraction consistently with the
router's definition. Counter-reset intervals are discarded. The parser no longer
mixes values from multiple station blocks. Old CSVs are preserved; appending new
rows to an incompatible CSV header is rejected.

The exporter rejects silently mixing legacy cumulative-PER records with interval
records. Training an interval candidate requires an explicit output path and a
separate manifest of preceding calibration baselines. This avoids overwriting the
deployed model or learning test baselines from future normal-labelled observations.
The deployed legacy forest has not been replaced; fixing future measurements does
not retroactively fix its historical training data or validate a new forest.
