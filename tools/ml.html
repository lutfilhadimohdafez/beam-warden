Why Isolation Forest
Unsupervised anomaly detection for WiFi telemetry

Isolation Forest is an unsupervised algorithm that isolates anomalies by random partitioning. Unlike supervised classifiers, it trains on normal traffic only — no labelled attack data required. Anomalies are isolated in fewer splits because they are rare and distinct, yielding a short average path length.


The short-path intuition: a point that is easy to isolate (few splits) is likely anomalous. The decision_function returns a score where >0 = normal, <0 = anomaly. This makes it effective for catching previously unseen attack patterns without retraining.

Notes

The model is trained offline on collected normal-mode telemetry. The StandardScaler is fitted on the same training set and serialised alongside the forest. At inference time, each incoming sample is scaled and scored; the raw decision_function value is pushed over the WebSocket as anomaly_score and the binary verdict as is_anomaly.


Synthetic attack replay (deauth/CSMA flooding) achieves 100% detection because the injected traffic is statistically extreme. Real-world accuracy (≥55% target) depends on capturing genuine attack telemetry — the model's contamination=0.02 threshold is calibrated for a low false-positive rate on normal WiFi environments.
